### 1. 自动播放

1. 在 Tampermonkey 中更新/重新安装 `0.4.0` 脚本。
2. 打开视频任务，确认服务商与 Key 配置无误，启动队列。
3. 观察视频是否自动开始；如果出现提示条「浏览器要求一次点击」，点击视频画面一次，确认随后自动继续。
4. 记录 Chrome/Edge 版本、是否静音、日志中的 `NotAllowedError`/`AbortError` 提示。
5. 仍需一次点击时，可在 `chrome://media-engagement` 查看站点媒体互动状态，或在浏览器站点设置中允许该站点自动播放/声音；企业策略要求的手势无法由脚本绕过。

### 2. 五分钟后台观察

1. 记录开始时间、当前章节和任务点进度（截图或文字）。
2. 将课程标签页切到后台，保持浏览器打开，不使用休眠/睡眠。
3. 5 分钟后回到页面，记录：视频 `currentTime`、任务点是否变为完成、面板日志、AI 调用次数（播放期间应为 0）。
4. 若页面被浏览器冻结或脚本暂停，如实记录，不把单次任务点完成当作五分钟后台测试通过。

记录模板：

```text
日期/时间：
课程与章节：
浏览器版本 / 是否静音：
开始进度：
结束进度：
平台任务点状态：
AI 调用次数：
异常与日志：
结论：通过 / 未通过（原因）
```

### 3. AI 与题目

1. 在「AI 设置」中只填写自己的 Key，不把 Key 发到聊天、截图或公开文件。
2. 逐项验证单选、多选、判断、填空、简答、图片题；记录模型、耗时、失败原因。
3. 确认有未解决题目时作业没有提交；图片题在视觉模型留空时保留待办。
4. 讨论题确认页面回执和「不重复发布」。

### 4. 考试

1. 仅使用低风险测验验证。
2. 确认脚本自动填答后出现人工交卷面板；确认前平台没有任何交卷请求。
3. 勾选并点击确认后，以平台结果为准；刷新后确认不应继承。
4. 不在真实考试中代替本人做提交决定。
